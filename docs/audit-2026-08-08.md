## Verdict

The toolkit is in good shape. All test suites pass (harness **255/255**, tooling **194/194**, bridge **98/98**; plugin typecheck clean). The read/extraction plane captures at or beyond what Figma's own paid Dev Mode tooling returns. The problems found are not in *what* is captured but in whether the output is **usable** by a coding agent: failed icon exports, payload bloat nothing consumes, no staleness detection, and oversized layer files with no size hints.

## 1. Official Figma MCP — verified facts (2026)

- The official MCP now has a **remote server** (`https://mcp.figma.com/mcp`) that requires **no desktop app** and is available on **all seats and plans**. The desktop/local server requires a Dev or Full seat on a paid plan. This is the biggest 2025→2026 change.
- **Rate limits key off where the FILE lives, not your seat.** Files in a Starter (free) plan are limited to **~6 read requests/month even if you hold a paid seat in another plan**. Figma's help center states this verbatim ("What if I'm rate-limited"). Paid seats on Starter files: Starter 200/day–10/min *by seat entitlement*, but the resource-location rule overrides it for Starter-hosted content (Figma's docs don't reconcile the two rows; the 6/month behavior is what forum reports confirm).
  - **Implication: this repo's free-plan Plugin-API thesis holds and is now documented by Figma itself.** The Plugin API remains the only unlimited free read path.
- Tool surface (24 tools): `get_design_context` (renamed from `get_code`; React+Tailwind default), `get_metadata` (sparse XML index — the cheap tool), `get_screenshot`, `get_variable_defs`, `get_motion_context`, `search_design_system`, Code Connect tools, and remote-only **canvas write** tools (`generate_figma_design`, `create_new_file`, `upload_assets`, …). Canvas write is **free during beta, will become usage-based paid** — a free local write plane stays a differentiator.
- REST tiers (effective 2025-11-17): file content and **images are Tier 1 = 6/month** on free files; **`/meta` is Tier 3 = 10/min** on free — staleness checks are effectively free. Variables REST API remains Enterprise-only.
- Sources: developers.figma.com/docs/figma-mcp-server/ (+ rate-limits-access, tools-and-prompts), help.figma.com articles 32132100833559 and 34963238552855, developers.figma.com/docs/rest-api/rate-limits.

## 2. Read plane — what's captured well

Verified module by module (`figma-plugin/src/`):

- **Layout** (`layout.ts:14-28`): auto-layout → real flexbox keys (`display/flexDirection/gap/padding/justifyContent/alignItems/flexWrap/rowGap/alignContent`), `inferredAutoLayout` fallback, full GRID support with per-track sizes and auto-flow, child placement/span/self-align, `sizeLimits`, `pin`, `grow`, `absolute`, `clip`/`scroll`, `strokesInLayout`, `layoutGrids`.
- **Paint/effects** (`paint.ts`, `effects.ts`): solid/gradient (stops + `gradientTransform`)/image/video/pattern/shader, image filters, `intrinsicSize`, per-side stroke weights, dash/cap/join, blur vs backdrop-blur vs shadows, NOISE/GLASS/TEXTURE, progressive blur.
- **Text** (`text.ts` — strongest module): per-run `getStyledTextSegments` with per-run tokens/styles, unit-aware lineHeight/letterSpacing, decoration detail, OpenType features, hyperlinks, lists/indent, truncation (`truncate`/`maxLines`/`autoResize`), `missingFont` flag.
- **Tokens** (`variables.ts`): bindings resolved at node/paint/gradient-stop/effect/text-run/component-prop level; library aliases resolved to a fixed point; `codeSyntax`, `scopes`, `tier`, `key`, per-mode values, `resolvedModes` for theming.
- **Components**: catalog with real `#uid` prop keys, defaults, variant options, `preferredValues`, descriptions, docs links; per-node `propRefs`, `overrides`, `detachedFrom`, `exposedInstances`.
- **Prototype** (`prototype.ts`): triggers incl. keyCodes/timeout, navigation, overlays, exact easing curves, `SET_VARIABLE`/`SET_VARIABLE_MODE`/recursive `CONDITIONAL`.
- **Handoff extras**: annotations, `devStatus`, dev resources, measurements, per-root reference PNG, diagnostics manifest.

The workflow already matches Figma's own measured best practices: screenshot + structured data paired (Figma's finding: better than either alone), metadata-first chunking (`figma_list_pages`/`figma_list_children`), and mapping to existing components/tokens rather than free-handing.

## 3. Punch-list — ranked by impact

1. **Failed vector exports have no fallback — icons unrecoverable.** The real live export reported `assetsFailed: 807`; 663 vector nodes carry no `asset` field. `collectAsset` (`figma-plugin/src/assets.ts:75-141`) has no pre-check for nodes with no visible paint / zero area and no `vectorPaths`/`fillGeometry` fallback. Fix: silently skip no-visible-paint nodes (counted separately from real failures) and capture `vectorPaths` as last resort.
2. **`inferredTokens` is 20.5% of the payload and often wrong.** `serialize.ts:45-59` emits `inferredVariables` for every unbound field — 2,151 occurrences; matches are value-coincidence (e.g. lineWidth tokens suggested for `opacity`). **Nothing consumes it** (no hits in `profiles/`, `.claude/`, `tooling/`). Drop it, or restrict to COLOR fields with 1 candidate.
3. **No staleness detection anywhere.** `tooling/drift-lint.js:121-132` diffs against the on-disk snapshot itself; nothing stamps or checks `fileKey`/`lastModified`. A days-old export passes as "clean" with total confidence. Fix is cheap: stamp exports via the free `/meta` endpoint (Tier 3, 10/min) and have drift-lint / `figma_status` warn when stale.
4. **Oversized layer files are unusable as instructed.** Real layer files are 5.3–7.6 MB; index entries (`bridge/pages-layout.js:78-84`, built at `collect.ts:455`) carry only `{name,id,type,page,pageId,file}` — no byte/node counts — while the skill says "read ONLY that file." Fix: add `bytes`/`nodes` to index entries + an offline depth-limited subtree slicer.
5. **Genuinely missing properties** (verified absent):
   - `numberOfFixedChildren` — sticky headers/footers/FABs inside scroll frames become plain flow children. Highest-value missing prop.
   - `page.backgrounds` + `page.prototypeBackgrounds` — no canvas-background signal for codegen. (~~`prototypeDevice`~~ REFUTED on verification: REST-only, not in the Plugin API / typings 1.131.0 — unactionable via the plugin.)
   - `exportSettings` — the designer's own presets encode intent (@2x/@3x/SVG and intended asset filename). Acknowledged deferred in ARCHITECTURE.md:181-183.
   - Skew — `serialize.ts:246-250` keeps only flip + rotation; sheared nodes lose their transform.

   *Verification notes (2026-08-08, second-pass agent against official docs):* `numberOfFixedChildren` and readable `exportSettings` CONFIRMED. Icon fallback should prefer `fillGeometry`/`vectorNetwork` over `vectorPaths` (docs call vectorPaths "simple, but incomplete"). `rootVariableCollectionId` could not be verified in u127–u133 update notes. u130's `figma.listAvailableShaders()`/`importShaderById()` closes the previously deferred ShaderPaint-detail gap. Rate-limit nuance: Starter Tier 1 is 6/month for View/Collab seats but 10/min for Dev/Full seats — the ceiling bites on seat type as well as file location. Section 6's pitfalls are practitioner consensus, not official Figma guidance.
6. **Noise to cut:**
   - `box.x/y` on children of auto-layout/grid parents (page-space coords codegen must never use; keep `w/h`).
   - Unconditional `widthMode`/`heightMode` incl. the `"fixed"` default (`serialize.ts:21-25`) — two keys on nearly every node.
   - The warnings manifest (896 entries — ~800 asset failures + 80 per-node `missingFont`) — aggregate/dedupe by kind.
7. **Captured but consumed by nothing** — either wire into skills/profiles or reconsider capturing: prototype `flows`, the entire GRID layout branch (`display:"grid"`, spans, self-align), `layoutGrids`, `measurements`, `devStatus`, `propTokens`, `exposedInstances`, `intrinsicSize`, `autoResize`/`maxLines`, `blendMode`/`rotation`/`flipped`, `sharedData`/`pluginData`. `profiles/web-tailwind.md` and `web-css-modules.md` are 19-line stubs mentioning none of grid/scroll/reactions/effects.
8. **Doc drift:** TESTING.md:22 claims harness 257/257; actual 255/255.
9. **New Plugin API surface to evaluate** (postdates last extractor audit): Motion — animation styles/timelines/keyframes (u130–u133), `SlotNode` (Slots GA 2026-06), grid-track APIs (u127), EASING/TIMING variable data types, `rootVariableCollectionId`, video export via `exportAsync`, Figma Draw nodes (text-on-path, brush effects, variable-width strokes).

## 5. Write plane (next-phase: code → design)

Current state: exactly **4 ops** — `createFrame`, `createText`, `setFill`, `setText` (`bridge/figma-mcp.mjs:141-170`, `figma-plugin/src/writes.ts:56-97`). Error reporting is good: non-transactional but each failure reports `failedAt`/`failedOp`/`error` plus applied ops; the plugin throws on invalid/removed/wrong-type nodes.

Ranked missing ops for a real round-trip:
1. `setAutoLayout` / layout props on **existing** frames (currently only at create time)
2. `createComponentInstance` — placing the design system's own components is the whole point
3. `setSize`/`move`/reparent for existing nodes
4. Generic shapes (`createRectangle`/`createEllipse`)
5. Delete/remove
6. `setVariableValue` / variable-binding writes (push token changes back)

## 6. Pitfalls checklist (industry-verified, for the codegen side)

Consistent across Figma's guidance and 2026 tool comparisons: non-auto-layout frames are the single highest-leverage failure; wrapper bloat → div soup; "Ignore auto layout" (absolute) misuse; missing interaction states (focus states most commonly missed — an a11y regression); never treat Figma line breaks as authoritative (different text engine than browsers); unnamed `Frame 427` layers give the agent nothing to name components from.
